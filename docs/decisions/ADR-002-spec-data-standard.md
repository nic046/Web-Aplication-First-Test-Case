# ADR-002: Add Spec Data Standard

## Status

Accepted

## Gap

The project has lifecycle setup and teardown but no dedicated owner for data classification,
parallel isolation, environment portability, typed sourcing, and exact expected-value sources.

## Options Considered

1. Extend the lifecycle or organisation skills.
2. Add a dedicated spec data skill for M0-M5.

Option 2 was selected because data robustness is a separate domain and feeds Arrange,
Assert, and Run phases.
